## Projetos em Destaque

### 🌾 AgroClimate Intelligence
Dashboard avançado para análise e visualização de dados climáticos e agrícolas. O projeto integra dados complexos de APIs geográficas e governamentais (como MapBiomas e IBGE), aplicando uma camada rigorosa de filtros de estado e otimização de performance para fornecer inteligência de mercado estruturada em tempo real.
* *Tecnologias:* Next.js, TypeScript, Tailwind CSS, API Integration.

### 📜 TechCode Editorial
Plataforma editorial minimalista construída sob as diretrizes estéticas de *Quiet Luxury*. O projeto adota uma arquitetura focada no conteúdo e na tipografia pura, utilizando microinterações ativas através de visores reativos que ganham iluminação cromática e pulso dinâmico via CSS.
* *Tecnologias:* Astro, TypeScript, Tailwind CSS, Vercel.

### 💰 Finanly
Mapeamento e desenvolvimento do Produto Mínimo Viável (MVP) de uma aplicação de gestão financeira. Focado na consolidação visual de fluxos de transação, análises preditivas e redução do esforço cognitivo do usuário no controle de orçamentos.
* *Tecnologias:* React, Next.js, Tailwind CSS.
